Object lifetime problem: returning a local's address
createNodeId() starts
creates a local int in its stack frame
↓
nodeId = 42
object is alive
↓
createNodeId() returns &nodeId
the frame is gone, and so is nodeId
↓
Dangling pointer
The pointer still holds an address, but no object lives there.
GCC 11 warns (-Wreturn-local-addr) and returns a null pointer instead, so my build crashed immediately with p = 0.
