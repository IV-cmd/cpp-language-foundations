Abstract classes: an interface that must be implemented
StorageNode
virtual void performIO() const = 0;
StorageNode generic; → error cannot declare variable to be of abstract type
NVMeNode
void performIO() const override
NVMeNode nvme; → fine prints NVMe parallel queues I/O
= 0 means "no implementation here, every concrete derived class must provide one". A class with at least one pure virtual function can only be used as a base.
