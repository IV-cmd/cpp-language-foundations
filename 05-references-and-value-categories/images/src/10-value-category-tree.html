The full picture (C++11 and later)
glvalue
"has identity": refers to a real object
lvalue
x, *ptr, arr[0]
xvalue
std::move(x)
prvalue
100, x + 1, getSize()
rvalue
"can be moved from"
xvalue sits under both: it names a real object, but the code has said it's OK to move from it. For this module, "lvalue vs rvalue" is enough.
