A pointer is a separate object. A reference is just another name.
int* ptr = &fileSize;

fileSize
Two objects. Use *ptr to reach the int. Can be null. Can point somewhere else later.
int& ref = fileSize;
100
fileSize a.k.a. ref
One object. Use ref directly. Must be bound when it's created, and stays bound.
Under the hood a compiler often implements a reference parameter as an address, but the language doesn't require it.
