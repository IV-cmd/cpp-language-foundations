With public data, nothing stops nonsense
open.usedCapacity = 2000; on a 1000-unit node
total 1000
used 2000
The program prints open node available: -1000. The object is in a state that can't exist in the real world.
An invariant is a rule that must always hold for an object, here 0 ≤ used ≤ total. Encapsulation is how a class enforces it.
