What new and delete each do
new StorageNode(1)
1. allocate
enough heap memory for a StorageNode
↓
2. construct
run the constructor in that memory
delete node
1. destroy
run the destructor
↓
2. free
give the memory back
Every new needs exactly one matching delete on every path out of the code, including early returns and exceptions. Phase 2 is about never writing these by hand.
