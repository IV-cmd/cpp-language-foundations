From main.cpp to a running process
g++ -E
1. Preprocess
handles #include, #define, #if
output: main.i
↓
g++ -S
2. Compile
parse, type-check, optimise
output: main.s (assembly)
↓
g++ -c
3. Assemble
assembly → machine code
output: main.o (one per .cpp)
↓
g++ *.o
4. Link
combines all .o files and libraries
output: a.out executable
↓
./a.out
5. Load
the OS maps the executable into memory
output: a running process
Plain g++ main.cpp runs steps 1–4 in one go. The flags stop after a given stage so you can look at the output.
