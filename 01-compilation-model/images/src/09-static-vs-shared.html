Static vs shared libraries: when does linking happen?
Static (libstorage-core.a)
storage-server
main code
copied in from .a
at build time
Self-contained. Upgrading the library means rebuilding.
Shared (libstdc++.so.6)
storage-server
main code
↓ mapped in by the dynamic loader at startup
libstdc++.so.6
shared by every process using it
Smaller binary. Fails at startup if the .so is missing.
