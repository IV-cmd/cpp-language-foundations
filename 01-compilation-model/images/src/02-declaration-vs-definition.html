Declaration vs definition
StorageNode.hpp
the declaration
class StorageNode {
public:
    void storeFile();
};
"This exists, and this is how you call it." Included by every file that uses it.
StorageNode.cpp
the definition
void StorageNode::storeFile() {
    std::cout << "Storing file\n";
}
"This is what it actually does." Compiled once, into one object file.
