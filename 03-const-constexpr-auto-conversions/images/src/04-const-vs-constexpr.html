const vs constexpr: when is the value known?
Compile time (g++ is running)
constexpr int BLOCK_SIZE = 4096;
value baked into the binary
constexpr int blocks = calculateBlocks(10000);
computed by the compiler: 3
static_assert(blocks == 3);
checked before the program exists
Run time (./a.out is running)
const int runtimeBlockSize = blockSizeFromConfig();
read-only, but only known now
calculateBlocks(sizeFromUser)
same function, runs as normal code
const = can't be modified after it's set. constexpr = must be computable during compilation.
