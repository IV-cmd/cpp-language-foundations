A lambda is an object of a class the compiler writes for you
I write
int threshold = 3;
auto byValue = [threshold](int id) {
    return id > threshold;
};
Roughly what the compiler generates
class __lambda_1 {
    int threshold;          // the capture
public:
    bool operator()(int id) const {
        return id > threshold;
    }
};
__lambda_1 byValue{threshold};
LambdasizeofWhat the object stores
[] {}1nothing (empty objects still take 1 byte)
[threshold]4a copy of the int
[&threshold]8the address of the int
Sizes from my run of lambdas.cpp. This is why capture by reference can dangle: the object holds an address.
