Which parameter type should I use?
SituationUseExample
Small and cheap to copy (int, bool, char, double)Tvoid setPort(int port)
Big object, only reading itconst T&void inspect(const FileMetadata& m)
Must change the caller's objectT&void update(FileMetadata& m)
The object might not existT* (or std::optional)StorageNode* findNode(int id)
A good default: start from const T& for anything bigger than a couple of pointers, and only drop the const if the function really has to change it.
