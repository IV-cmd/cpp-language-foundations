Reading a function template
SyntaxMeaning
template <typename T>what follows is a template with one type parameter, T
T findMaximum(T a, T b)both parameters and the return value have that type
findMaximum(10, 20)T is deduced from the arguments: int
findMaximum<double>(10, 20.5)T given explicitly; 10 converts to double
typename vs classidentical in this position: template <class T> means the same
